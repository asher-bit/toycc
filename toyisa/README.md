# toyisa —— 迷你教学 ISA：流片前工具链的第一件交付物

一个 **12 条指令、几百行代码**的完整迷你工具链闭环，把主教材第 27~29 课的
"模拟器、二进制、差分测试"落成可以逐行读、可以改的代码。

```text
isa.py         ISA 规范: 12 条指令 + 32 位定长编码(手算可验)
assembler.py   两遍汇编器: 段/符号表/重定位记录(第 29 课的格式概念)
loader.py      链接器: 布局 + S+A 修补重定位(第 29 课的手算变成代码)
iss.py         功能模拟器 #1(类式, 带异常与提交点语义)
ref.py         参考执行器 #2(函数式, 独立编写 —— 差分测试的"第二份实现")
gen.py         随机程序生成器(只向前跳, 保证可终止)
diff.py        差分测试 + 覆盖率门禁(第 27 课的方法论)
demo.py        一键演示(求和程序 + 异常路径 + 300 程序差分)
tests/         pytest 回归套件
```

## 一分钟跑起来

```bash
python -m toyisa.demo                 # 汇编→链接→双执行→差分→覆盖率门禁
python toyisa/tests/run_tests.py      # 回归套件(零依赖; 有 pytest 则 python -m pytest toyisa/tests)
```

## ISA 速览（12 条）

| 指令 | 语义 | 字段 |
|---|---|---|
| `halt` / `nop` | 结束 / 空操作 | — |
| `add rd, rs1, rs2` | 加 | R 型 |
| `sub rd, rs1, rs2` | 减 | R 型 |
| `mul rd, rs1, rs2` | 乘(低 32 位) | R 型 |
| `movi rd, imm12` | 装符号扩展立即数 | I 型 |
| `ld rd, imm12(rs1)` | 读 4 字节(须对齐) | M 型 |
| `st rs2, imm12(rs1)` | 写 4 字节(须对齐) | S 型 |
| `beq rs1, rs2, imm12` | 相等跳(字偏移) | B 型 |
| `j imm20` | 跳转(字偏移) | J 型 |
| `jal rd, imm20` | 链接跳转(rd=pc+4) | J 型 |
| `jr rs1` | 寄存器跳转(返回) | R 型 |

- 16 个寄存器 r0..r15，**r0 恒为 0**（真实 ISA 的 zero 寄存器约定）；
- 编码 32 位定长：`[31:24] opcode | [23:20] rd | [19:16] rs1 | [15:12] rs2 | [11:0] imm12`（J 型用 `[19:0] imm20`）——每条指令都能**手算编码**；
- 内存 64 KiB 字节寻址；`ld/st` 要求 4 字节对齐，违反即异常；
- 异常三类：非法指令 / 未对齐访存 / 越界；ISS 实现**提交点语义**（先检查、后写回）。

## 任务链：给 ISA 加一条指令（第 10 课任务模式）

以加 `sll`（逻辑左移）为例，五步全在 toyisa 里练：

1. **规范**：`isa.py` 的 `ISA` 表加一行（opcode 0x0C、R 型、语义说明）；
2. **汇编器**：`assembler.py` 的 R 型分支自动支持（`_encode_one` 已按 R 型处理，只需确认语法）；
3. **ISS + 参考**：`iss.py` 与 `ref.py` 各加一个分支——**两份独立实现都要改**；
4. **差分**：`gen.py` 的 `_rand_alu` 把 `sll` 加进随机池；
5. **测试**：`tests/` 加编码手算用例 + 语义用例，跑 `python -m pytest tests/`。

验收标准：`python -m toyisa.demo` 全绿 + 覆盖率门禁仍为 12/13（新指令被随机测试覆盖）。
这也是自研芯片团队"给 ISA 加指令"的真实流程：**规范 → 工具链全链 → 差分 → 覆盖率**。
