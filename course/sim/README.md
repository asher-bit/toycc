# 模拟器专题：性能模型与周期模型的设计

第 27 课的纵向深入。主教材回答"模拟器是什么、为什么是工具链第一件交付物"；
本专题回答"**性能模型和周期模型具体怎么设计**"——从逻辑原理到设计细节。

```text
"快不快"的两层工具:
  解析式性能模型(估整体, 毫秒级)
      ↓ 不够精确时
  逐周期模拟器(逐周期推演, 慢 2~4 个数量级)
```

## 分章

1. [性能模型的设计](01_performance_models.md)：特征提取 → 公式/系数 → 输出；
   解析式、trace 重放、机器学习代价模型三条路线；参数化与悲观校准。
2. [周期模型的设计](02_cycle_models.md)：功能核与时序模型分离；五级流水
   三种冒险；顺序/乱序、延迟/吞吐、存储层次；GPU 特有建模对象；校准验证链。

## 配套代码（toyisa）

- `toyisa/cycle.py`：五级顺序流水的周期模拟器（计分板 + 访存延迟 + 分支冲刷，
  IPC 与 stall 分类），22 个回归测试里含手算验证；
- `python -m toyisa.demo` 第 4 节：同一程序先跑 ISS（对不对）再跑周期模型
  （快不快），并做 mem_latency 参数化实验；
- 延伸任务：加前向网络、命中/缺失分级延迟——都在 `toyisa/README.md`。

## 推荐顺序

先读第 27 课第 3 节与 3.2 节手算 → 跑 `python -m toyisa.demo` 第 4 节 →
回到本专题两章 → 完成各章检查点。
